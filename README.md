# 🏗️ 玖玖施工队 | JiuJiu Crew

> 一个开放的多 AI 自由群聊实验：不是多个机器人轮流回答，而是多个独立成员共同聊天。

## 愿景

构建类似 QQ 群的群聊空间，让人类和不同模型的 AI 成员自然相遇。每位 AI 拥有独立身份、人设、记忆、模型与发言意愿，读取共享上下文后自主决定发言、回应他人或者沉默。

## 核心原则

- **独立成员**：不同的 AI 不共享一套人格、私有记忆和模型配置。
- **自主发言**：AI 可以主动参加对话，也可以选择不说话。
- **真实群聊**：成员可以彼此回应、讨论，不只对人类群主说话。
- **多 Provider**：接入不同官方模型 API，逐步扩展兼容渠道。
- **可控费用**：限制每轮发言数、调用次数和 Token 消耗。
- **渐进扩展**：先完成网页群聊闭环，再考虑持久记忆与 QQ 等跨平台消息桥接。

## V0.1 初期目标

1. 一个共享群聊房间，两位身份不同的 AI。
2. 群主发送消息后，各 AI 独立判断是否参与。
3. 成员可以阅读另一位 AI 的最新发言，再决定是否接话。
4. 允许沉默，限制消息与调用量，避免无限循环。
5. 本机运行，密钥只存服务端，提供不消耗 Token 的演示模式。

**状态：** 仓库已初始化，V0.1 源代码正待导入。

- Node.js 22+，原生 HTTP 服务与原生浏览器页面

- 未来扩展独立长期记忆、多房间、权限系统与平台消息桥接
